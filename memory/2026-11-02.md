## 归档：B档启动内存刀（降启动期 / 常驻 RSS，不伤编辑响应）

### 改了什么
1. **砍死启动路径**
   - 不再 `init`：`watcher_debug` / `telemetry_log` / `remote_debug`
   - 删除对应源文件；工具条不再挂 `TelemetryLogToolbarItemView`
   - 删除已空的 `eager_load_active_theme_and_icon_theme`（无 extension 主题预取）
2. **缩默认嵌入资源（`crates/assets`）**
   - 不嵌：`sounds/**`（calls/AI）、`prompts/**`
   - 字体只嵌首屏必需：Plex Regular/SemiBold + Lilex Regular/Bold/Italic（去掉 UI Italic、SemiBoldItalic、BoldItalic）
   - 排除 AI/协作/预测图标与营销图；保留 `zed_logo` / `grid`
3. **主题按需解析**
   - 启动只 `serde` 当前（及 system 对侧）主题所在 family（默认 One ≈27KiB）
   - 主题选择器 / 设置页主题下拉打开时 `ensure_all_bundled_themes_loaded`
   - 设置切到尚未加载的内置主题时按名补载，必要时全量补载
4. **Linux `prewarm_fonts`**：只预热已嵌入字重，避免未嵌入变体的系统回退匹配
5. **未动**：语法白名单 / wasmtime；终端、搜索、Git、项目面板、大纲、命令面板、设置

### 为什么能降内存 / 不伤响应
- 少把 ~600KiB 斜体等字重拷进 fontdb；少映射 ~0.8MiB+ 声音/prompt/无用图标图
- 启动少解析 ayu+gruvbox（~120KiB JSON → 堆上 Theme 图）
- 去掉开发/遥测/远程模拟的 observe_new 与工具条 Entity
- 打开文件 / 输入 / 搜索 / Git 的热路径未改；语法仍按需加载

### 未做 / 风险
- GPUI/Metal 本身、wasmtime 引擎常驻未动（禁止硬卸）
- 去掉的字体变体若某处强制 Italic UI / BoldItalic，会走系统回退，观感略差
- `--features calls` 时声音不再嵌入，需另补资源路径
- IconName 仍可能指向已排除 SVG（默认 UI 不渲染那些图标）
- `client` / `remote` 壳、`FeatureFlagStore`、全量 grammar 注册表仍在
- 未测 release 实机 RSS
