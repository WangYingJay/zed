## 归档：修复 v0.1.2-slim `.vue` 状态栏 Unknown / 无高亮

1. 官方 Zed 的 **Vue.js**（以及 **HTML**）靠扩展提供（`zed-extensions/vue`、`extensions/html`），不是 `crates/languages` 内置语言。
2. B档第二刀起：`zed` 只 `extension::init` 轻量 `ExtensionHostProxy`，**不拉起 `extension_host` WASM** → 扩展语言/grammar 永不注册。
3. 打开 `ApiAccessLogDetail.vue` 时 `language_for_file` 匹配失败 → 状态栏 **Unknown**、无 tree-sitter 高亮。非用户 `file_types` 设置问题。
4. 此前 main 曾用 crates.io `tree-sitter-vue-next` 白名单尝试；slim 实测 `.vue` 仍可能 Unknown，故改用 vendored path crate。

### 改了什么
1. **内置 Vue.js**
   - 新增 `crates/tree_sitter_vue`：vendor `tree-sitter-grammars/tree-sitter-vue@7e48557`（与 zed-extensions/vue 的 grammar pin 一致；上游 Cargo.toml 仍钉旧 tree-sitter，不能直接 git 依赖）
   - `crates/grammars/src/vue/*`：从扩展拷 config/queries；`path_suffixes = ["vue"]`，显示名 `Vue.js`
   - `grammars` 白名单 + `languages::init` 注册 `vue`
2. **顺带内置 HTML**（同根因；Vue 注释注入也引用 `html`）
   - `crates/grammars/src/html/*` 自 `extensions/html/languages/html`
   - 白名单加入已有 workspace dep `tree-sitter-html`
3. **未动**：wasmtime；其余既有白名单语言保留；未恢复 extension_host
